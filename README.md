# จับเวลาจานมิเตอร์

เว็บแอปหน้าเดียวสำหรับคำนวณเวลาต่อ 1 รอบ (นาที) และพลังงานต่อ 1 รอบ (Wh) ของจานมิเตอร์ไฟฟ้า
พร้อมจับเวลาแถบดำบนจานจากกล้องสด วิดีโอ หรือกดเอง และชดเชย % ความคลาดเคลื่อน

- `core.js` สูตรคำนวณและตัวตรวจจับแถบดำ (ไม่มี DOM)
- `core.test.js` เทสต์: `node --test`
- `page.html` หน้าเว็บ (มี `/*CORE*/` ไว้แทรก core.js)
- `build.js` สร้าง `index.html` สำหรับ GitHub Pages: `node build.js`

กล้องสดต้องเปิดผ่าน https (เช่น GitHub Pages)
